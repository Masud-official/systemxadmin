# Telegram Bot Command Center for Android

এটি একটি টেলিগ্রাম বট যা Firebase Realtime Database-এর মাধ্যমে অ্যান্ড্রয়েড অ্যাপকে রিমোটলি কন্ট্রোল করতে পারে।

### Environment Variables (Render/Railway-তে সেট করতে হবে):
- `TELEGRAM_BOT_TOKEN`: আপনার বটের টেলিগ্রাম টোকেন
- `FIREBASE_DATABASE_URL`: আপনার ফায়ারবেস রিয়েলটাইম ডাটাবেজের ইউআরএল
